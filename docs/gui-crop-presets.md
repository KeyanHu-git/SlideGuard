# GUI 裁剪预设与按页设置

GUI 里的裁剪框、扩边比例和参考像素安全边现在合并为一个 `CropSpec`。内置预设、自定义预设、按页草稿和最终导出请求都传递这份数据；它们不会调用另一套裁剪代码，也不会改写 PPTX。

## 三个内置预设

| 名称 | 模式 | 四边扩展 | 固定安全边 | 适合场景 |
| --- | --- | ---: | ---: | --- |
| 自动紧边 | 自动 | 0% | 0 px | 需要最小画布，且图形没有需要额外保留的外缘效果 |
| 论文安全边距 | 自动 | 每边 2% | 16 个参考像素 | 图中有阴影、发光或很靠边的细线 |
| 整页 | 手动 | 0% | 0 px | 保留整张幻灯片画布 |

“论文安全边距”是 SlideGuard 的保守起点，不是某本期刊规定的版心尺寸。2% 按紧边结果的宽高分别计算，之后再加 16 个参考像素，最后夹在幻灯片边界内。

## 自定义预设

先把当前页调到需要的状态，再点“保存当前为自定义预设”。名称相同（忽略大小写）时覆盖原值，名称不同则新增。自定义预设保存在：

```text
%LOCALAPPDATA%\SlideGuard\gui-crop-presets.json
```

文件使用 `gui-crop-presets.schema.json` 的版本 1 格式，并通过临时文件加原子替换写入。预设仅保存 `CropSpec`，不保存源文件路径、输出目录、页码或大小预算。

## 按页保存与复制

每页有自己的 `CropSpec`。离开当前页前，GUI 会先保存该页设置；返回时恢复。要把当前页复制到别的页，在“复制到页”中输入 `2,4-6` 这类页码范围，再点“复制”。无效页码和超出文稿范围的页码不会写入草稿。

带缩略图的页面列表由 KEY-141 单独实现。它以后只需把选中的页号交给同一个复制方法，不需要重做预设或裁剪计算。

草稿格式升到版本 2，`pageCrops` 以页码保存 `CropSpec`。版本 1 草稿在读取时迁移：原来的当前页设置会成为该页的第一条按页记录。下一次保存后文件自然写成版本 2。

## 导出边界

导出时，GUI 从当前控件读取一份 `CropSpec`，再调用 `CropSpec.to_request_document()` 生成公开 `ExportRequest.crop`：

- 手动模式带 `boundsPercent`；
- 自动模式不带 `boundsPercent`；
- 两种模式都带四边 `expandPercent` 和 `paddingPx`。

后续仍由 `prepare_request()` 校验，再交给同一导出引擎。预设名称和自定义预设 ID 不进入导出请求，也不影响配置指纹。
