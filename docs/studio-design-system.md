## 视觉约束

- 主题定义在 Theme.qml。白色面板、中性灰画布、蓝色编辑状态、绿色输出范围。颜色不写进输出文件。
- 中文 Microsoft YaHei UI，英文品牌 Segoe UI；正文12px、说明11px、分组标题13px。操作不能只靠说明才能找到。
- 4px基础步长，8px小间距、16px面板内边距。控件32px高、4px圆角、16px线性图标；可见裁剪手柄8px，点击区24px。
- ActionButton、Choice、ValueSlider和Glyph共用。默认、悬停、按下、选中、禁用与键盘焦点分开处理。
- 只在导出主操作使用实色填充。工具栏采用轻背景，视图切换同组排列。去掉口号、装饰编号和字母Logo。
- 文件名与保存路径中间省略，悬停显示完整路径。长路径不得扩大属性栏。

## 工作区与行为

文档栏下方是页面导航、画布、288px属性栏。页面导航在窄窗口收至132px，其余使用168px。最小窗口1000×700。属性可滚动，检查与导出固定在独立底栏。

当前页面显示真实源图缩略图，sourcePreviewUrl独立于结果预览。尚未渲染的页面显示“点击预览”，不伪造缩略图。全量多页缩略缓存与逐页草稿仍由KEY-251负责。

“适合选区”只调整视口比例和平移，以最终输出范围居中。首次生成源图或切换结果时适配；每次修改边距不自动跳动。1:1相对参考像素，不代表嵌入位图获得额外细节。源图白底不代表输出背景，透明PNG使用真实Alpha。

边缘留白默认四边联动，可一击0/1/2/5%或拖动滑杆，精确坐标按需展开。扩边仍按选区宽高计算，裁限在幻灯片内。页外透明扩展未实现。
